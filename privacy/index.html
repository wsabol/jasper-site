Privacy policy

Jasper is a privately operated AI personal assistant. This policy explains what information the application accesses and how it is used.

Who operates Jasper

Jasper is operated privately by Will Sabol. It is not a public service and is available only to the operator and explicitly authorized accounts.

Information accessed

When authorized, Jasper accesses limited Google data needed for its personal-assistant workflows:

  • Gmail: messages and metadata matching a configured label, plus the ability to apply a processing label.
  • Google Calendar: event information needed to compare existing events and create or update approved events on a configured calendar.
  • OAuth account data: authorization credentials and token metadata needed to maintain access.

Jasper does not use Google data for advertising or sell it.

How information is used

Gmail information is used to identify events, deadlines, and reminders. Calendar information is used to avoid duplicates and to write approved events. The application maintains an internal record of proposed actions and calendar links so that repeated messages can be handled sensibly.

Authorization

Access requires explicit authorization through Google OAuth. The application requests Gmail read/modify access and Calendar read/event-writing access for the configured account. Authorization can be revoked at any time from the Google Account security settings.

Storage and processing

OAuth credentials, application records, logs, and generated digests are stored on the operator-controlled computer running Jasper. The application uses local SQLite storage and local token files. Selected Gmail message content and event information are sent to OpenAI through its API to extract and match calendar information. OpenAI is an external service provider; its handling of submitted data is governed by its applicable terms and privacy documentation.

Sharing

Jasper does not sell personal information or share it for advertising. Information is transmitted to Google to read and update the authorized services, and to OpenAI when AI extraction or event matching is run. No analytics, tracking pixels, or other advertising services are included on this website.

Jasper's use and transfer of information received from Google APIs complies with the Google API Services User Data Policy, including its Limited Use requirements. Google data is used only to provide the application's user-facing personal-assistant features and is not used for advertising, sold, or transferred for unrelated purposes.

Retention and deletion

There is no automatic public-service retention schedule. Information remains in the local application database, logs, digests, and token files until the operator deletes it or removes the relevant files. To stop access, revoke Jasper's Google authorization in the Google Account security settings and contact the operator to request deletion of locally stored application data.

Security

Jasper is operated as a local application. Credentials are kept outside the public website and token files are written with restricted file permissions. The review and administration interfaces are local-only. No security certification is claimed, and no system can guarantee absolute security.
